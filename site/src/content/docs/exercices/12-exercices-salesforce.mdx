## Mise en contexte

**Distributions Boréale Inc.** est une entreprise québécoise de distribution alimentaire établie à Trois-Rivières. 
Elle dessert des restaurants, épiceries, hôtels et institutions à travers le Québec.

L'entreprise utilise actuellement un vieux logiciel de gestion pour suivre ses clients et ses ventes. 
La direction a décidé de migrer vers **Salesforce** pour centraliser l'information commerciale. 
L'ancien système a exporté les données dans **quatre fichiers CSV** :

| Fichier | Contenu | Objet Salesforce visé |
|---|---|---|
| `comptes_boreale.csv` | Entreprises clientes | Comptes |
| `contacts_boreale.csv` | Personnes-ressources chez les clients | Contacts |
| `leads_boreale.csv` | Pistes captées lors d'événements | Leads |
| `opportunites_boreale.csv` | Ventes en cours de négociation | Opportunités |

Ton mandat : **ouvrir ces fichiers dans Excel, nettoyer les données, les consolider, produire une analyse avec des TCD**, puis préparer les fichiers pour l'importation dans Salesforce.

<Aside type="tip" title="Compétences visées">
Cet exercice met en pratique l'importation de fichiers CSV, le nettoyage de données (SUPPRESPACE, formats, doublons), 
la consolidation multi-feuilles, les tableaux croisés dynamiques et les graphiques croisés dynamiques.
</Aside>

## Partie 1 : Importation des fichiers CSV

<Steps>
1. Ouvre un **nouveau classeur vide** dans Excel.

2. Importe le fichier `comptes_boreale.csv` :
   - Va dans **Données** → **Obtenir des données** → **À partir d'un fichier** → **À partir d'un fichier texte/CSV**.
   - Sélectionne `comptes_boreale.csv`.
   - Dans l'aperçu, vérifie que le **délimiteur** est bien le **point-virgule** (`;`).
   - Clique sur **Charger**.

3. Renomme la feuille créée : double-clique sur l'onglet et nomme-la **Comptes**.

4. Répète les étapes 2 et 3 pour les trois autres fichiers :
   - `contacts_boreale.csv` → feuille **Contacts**
   - `leads_boreale.csv` → feuille **Leads**
   - `opportunites_boreale.csv` → feuille **Opportunités**

5. Enregistre le classeur sous le nom `migration_boreale.xlsx`.
</Steps>

<Aside type="caution" title="Encodage des caractères">
Si les accents s'affichent mal (Ã© au lieu de é), change l'**Origine du fichier** à **65001 : Unicode (UTF-8)** dans la fenêtre d'importation.
</Aside>

**Vérifie ton résultat** : tu devrais avoir un classeur avec 4 feuilles contenant respectivement 15, 20, 12 et 15 lignes de données (sans compter les en-têtes).

## Partie 2 : Nettoyage des données

Les données exportées de l'ancien système contiennent plusieurs problèmes courants. Tu vas les corriger feuille par feuille.

### 2.1 Feuille Comptes

<Steps>
1. **Supprime la colonne `ID_Ancien`** — c'est un identifiant interne de l'ancien système, inutile pour Salesforce.

2. **Corrige les espaces parasites** dans la colonne `Nom du compte`. Utilise la formule `SUPPRESPACE()` dans une colonne temporaire, puis colle les valeurs corrigées par-dessus l'original.

   <Aside type="tip" title="Technique rapide">
   Dans une cellule libre (ex. : J2), entre `=SUPPRESPACE(A2)` (où A2 contient maintenant le nom du compte après suppression de la colonne ID). Copie la formule vers le bas, sélectionne la plage résultante, copie-la, puis colle en **Valeurs uniquement** par-dessus la colonne d'origine. Supprime ensuite la colonne temporaire.
   </Aside>

3. **Identifie et supprime le doublon**. Deux lignes représentent la même entreprise (même nom, même téléphone, même adresse).
   - Utilise **Données** → **Supprimer les doublons** ou repère-le visuellement après avoir nettoyé les espaces.

4. **Vérifie les données manquantes** : deux comptes n'ont pas de site web. C'est acceptable — laisse les cellules vides.
</Steps>

**Vérifie ton résultat** : la feuille Comptes devrait maintenant contenir **14 lignes** de données (le doublon Transport Saguenay Express a été supprimé).

### 2.2 Feuille Contacts

<Steps>
1. **Supprime la colonne `ID_Contact`** — même raison que pour les comptes.

2. **Corrige les espaces parasites** dans les colonnes `Nom` et `Prénom` avec `SUPPRESPACE()`.

3. **Standardise les numéros de téléphone**. Certains utilisent des tirets (`418-555-0124`), d'autres des espaces (`418 555 1235`) ou aucun séparateur (`8195550149`). Choisis un format uniforme (ex. : `418-555-0124`) et corrige les incohérences manuellement ou avec des formules de texte.

   <Aside type="note" title="Astuce formatage téléphone">
   Pour le numéro sans séparateur (`8195550149`), tu peux utiliser :
   ```
   =GAUCHE(A2;3)&"-"&STXT(A2;4;3)&"-"&DROITE(A2;4)
   ```
   </Aside>

4. **Repère le contact sans courriel** (Daniel Lapointe). Note-le, mais ne supprime pas la ligne — un contact sans courriel reste un contact valide.
</Steps>

**Vérifie ton résultat** : 20 contacts, tous avec des noms propres (sans espaces parasites) et des téléphones dans un format uniforme.

### 2.3 Feuille Leads

<Steps>
1. **Supprime le doublon** (Amélie Bouchard apparaît deux fois — la note « Doublon — même lead » confirme qu'il s'agit d'une erreur).

2. **Uniformise la colonne `Statut`**. Les valeurs utilisent des casses incohérentes : « Nouveau », « NOUVEAU », « nouveau », « contacté », « Contacté », « Qualifié ». Uniformise en **première lettre en majuscule** :
   ```
   =MAJUSCULE(GAUCHE(A2;1))&MINUSCULE(DROITE(A2;NBCAR(A2)-1))
   ```
   Ou corrige manuellement — il n'y a que 11 lignes.

3. **Note le téléphone manquant** (Josée Lafleur) et la **possible coquille** dans le courriel d'André Tanguay (`microdufford` au lieu de `microdufjord`). Signale ces anomalies dans une note, mais ne les invente pas — tu n'as pas l'information correcte.
</Steps>

**Vérifie ton résultat** : 11 leads uniques avec des statuts uniformisés.

### 2.4 Feuille Opportunités

<Steps>
1. **Corrige la colonne `Montant`** :
   - La valeur `45000` de « Logistique régionale Saguenay » contient un **espace initial** — supprime-le.
   - La valeur `110000 $` de « Contrat annuel produits laitiers » contient un **symbole de devise** — retire le ` $` pour ne garder que le nombre.
   - Vérifie que toutes les valeurs sont bien reconnues comme des **nombres** (alignées à droite dans Excel). Si certaines sont en format texte, utilise `VALEUR()` pour les convertir.

2. **Corrige le format de date incohérent** :
   - L'opportunité « Approvisionnement boulangerie » a une date au format `15/06/2026` alors que les autres utilisent `2026-06-15`. Corrige pour que toutes les dates soient dans le même format.

3. **Convertis la colonne `Probabilité (%)` en format pourcentage** : divise les valeurs par 100 si nécessaire et applique le format Pourcentage.
</Steps>

**Vérifie ton résultat** : 15 opportunités, montant total = **797 000 $**. Si ta somme ne donne pas ce résultat, c'est qu'une valeur est encore en format texte.

## Partie 3 : Consolidation

Crée une nouvelle feuille nommée **Tableau de bord** qui consolide les informations clés des quatre feuilles.

<Steps>
1. **En-tête du tableau de bord** : en A1, inscris « Distributions Boréale — Tableau de bord migration CRM ». Fusionne les cellules A1:D1, applique un style de titre (gras, taille 14).

2. **Section Inventaire des données** (à partir de la ligne 3) — Crée un petit tableau récapitulatif avec des formules qui comptent dynamiquement les données de chaque feuille :

   | Objet Salesforce | Nombre d'enregistrements |
   |---|---|
   | Comptes | *(formule : NBVAL sur la colonne des noms, moins 1 pour l'en-tête)* |
   | Contacts | *(idem)* |
   | Leads | *(idem)* |
   | Opportunités | *(idem)* |

3. **Section Indicateurs financiers** (quelques lignes plus bas) — Calcule les métriques suivantes à partir de la feuille Opportunités, en utilisant des formules (pas de valeurs saisies à la main) :

   | Indicateur | Formule suggérée |
   |---|---|
   | Montant total du pipeline | `SOMME()` sur la colonne Montant |
   | Nombre d'opportunités gagnées | `NB.SI()` sur la colonne Étape = "Conclue gagnée" |
   | Valeur des opportunités gagnées | `SOMME.SI()` |
   | Valeur du pipeline actif (excluant les gagnées) | Total moins les gagnées |
   | Montant moyen par opportunité | `MOYENNE()` |

4. **Section Contacts par compte** — Utilise `NB.SI()` pour compter le nombre de contacts associés à chaque compte. Tu peux le faire dans un petit tableau ou dans une colonne ajoutée à la feuille Comptes.
</Steps>

**Vérifie tes résultats** :

| Indicateur | Valeur attendue |
|---|---|
| Nombre de comptes | 14 |
| Nombre de contacts | 20 |
| Nombre de leads | 11 |
| Nombre d'opportunités | 15 |
| Montant total du pipeline | 797 000 $ |
| Opportunités gagnées (nb) | 3 |
| Valeur des opportunités gagnées | 140 000 $ |
| Pipeline actif | 657 000 $ |
| Montant moyen par opportunité | 53 133 $ |

## Partie 4 : Analyse avec TCD

### 4.1 TCD du pipeline par étape

<Steps>
1. Sélectionne les données de la feuille **Opportunités** (y compris les en-têtes).
2. Insère un **tableau croisé dynamique** dans une nouvelle feuille. Nomme cette feuille **TCD-Pipeline**.
3. Configure le TCD :
   - **Lignes** : Étape
   - **Valeurs** : Montant (Somme) **et** Montant (Nombre)
4. Trie le TCD par montant décroissant.
</Steps>

**Vérifie ton résultat** :

| Étape | Somme des montants | Nombre |
|---|---|---|
| Proposition | 312 000 $ | 4 |
| Conclue gagnée | 140 000 $ | 3 |
| Négociation | 135 000 $ | 3 |
| Prospection | 125 000 $ | 3 |
| Qualification | 85 000 $ | 2 |

### 4.2 TCD des opportunités par compte

<Steps>
1. Crée un **deuxième TCD** dans la même feuille (ou une nouvelle).
2. Configure :
   - **Lignes** : Compte
   - **Colonnes** : Étape
   - **Valeurs** : Montant (Somme)
3. Ce TCD te donne une vue croisée : combien chaque client représente à chaque étape du pipeline.
</Steps>

**Vérifie ton résultat** : Épicerie Chez Marco devrait afficher **175 000 $** au total (85 000 $ en Négociation + 90 000 $ Conclue gagnée). Hôtel & Spa des Laurentides devrait afficher **92 000 $** (52 000 $ en Proposition + 40 000 $ en Qualification).

### 4.3 Graphiques croisés dynamiques

<Steps>
1. À partir du TCD de la section 4.1, insère un **graphique croisé dynamique** de type **histogramme groupé**. Ce graphique montre visuellement la valeur du pipeline à chaque étape.

2. À partir du même TCD, crée un **graphique en secteurs** (camembert) montrant la répartition des montants par étape. Ajoute les étiquettes de données en pourcentage.

3. Mets en forme les graphiques :
   - Ajoute un titre descriptif (ex. : « Pipeline de ventes par étape — Distributions Boréale »).
   - Applique un style de couleurs cohérent.
   - Assure-toi que les montants en dollars sont lisibles (pas de décimales inutiles).
</Steps>

<Aside type="tip" title="Lecture du graphique en secteurs">
La part « Proposition » devrait dominer le graphique (~39 % du pipeline total). C'est une information utile pour la direction : une grande partie du potentiel de revenus est encore au stade de la soumission.
</Aside>

## Partie 5 : Préparation pour Salesforce

Avant d'importer les données dans Salesforce avec le **Data Import Wizard**, les fichiers doivent respecter un format précis.

### 5.1 Correspondance des colonnes

Salesforce utilise des **noms de champs en anglais** dans son importateur. Crée une copie de chaque feuille nettoyée et renomme les colonnes selon la correspondance suivante :

<Tabs>
<TabItem label="Comptes">

| Colonne actuelle | Nom Salesforce |
|---|---|
| Nom du compte | Account Name |
| Industrie | Industry |
| Téléphone | Phone |
| Adresse | Billing Street |
| Ville | Billing City |
| Province | Billing State |
| Code postal | Billing Zip |
| Site web | Website |

</TabItem>
<TabItem label="Contacts">

| Téléphone | Phone |

</TabItem>

### 5.2 Exporter en CSV

<Steps>
1. Pour chaque feuille renommée, enregistre-la dans un fichier CSV séparé :
   - **Fichier** → **Enregistrer sous** → Format **CSV UTF-8 (délimité par des virgules) (.csv)**.
   - Nomme les fichiers : `sf_comptes.csv`, `sf_contacts.csv`, `sf_leads.csv`, `sf_opportunites.csv`.

2. **Important** : Salesforce attend des virgules comme délimiteurs (et non des points-virgules). Le format « CSV UTF-8 » d'Excel utilise la virgule par défaut, même en français.
</Steps>

<Aside type="caution" title="Ordre d'importation dans Salesforce">
L'ordre d'importation est crucial à cause des relations entre objets :
1. **Comptes** en premier (les autres objets y font référence)
2. **Contacts** en deuxième (liés aux comptes par `Account Name`)
3. **Opportunités** en troisième (liées aux comptes)
4. **Leads** en dernier (ils sont indépendants)

Si tu importes les contacts avant les comptes, Salesforce ne pourra pas créer les liens entre eux.
</Aside>
